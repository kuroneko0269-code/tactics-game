## フェーズ 0: 基盤（今回）

- プロジェクトの雛形（TypeScript / Vite / Three.js / Vitest）と、lint・型チェック・テスト・ビルドのコマンド
- core が描画・画面に依存しないことの自動検査、シード付き乱数
- 動作確認用の画面: 高低差のある 8×8 マップ、90度ずつのカメラ回転、タップでマス選択、仮の人形1体
- GitHub Actions: PR での自動検査、main から GitHub Pages への自動公開
- CLAUDE.md、本ロードマップ、GAME_DESIGN.md

## フェーズ 1: 戦闘コア

1マップ・4ジョブで、1回の戦闘が最初から最後まで遊べる状態にする。

- 移動（高低差による移動制限を含む）
- 攻撃
- 詠唱（指定から発動までの待ち時間）
- 高低差による命中・威力などへの影響
- 向き（正面・側面・背面での違い）
- 敵 AI（コンピューターが操作する敵の思考）
- 勝敗判定

## フェーズ 2: 育成ループ

戦闘 → 育成 → 次の戦闘、の繰り返しが楽しめる状態にする。

- JP（ジョブポイント。戦闘で得てアビリティ習得に使う）
- アビリティ継承（覚えたアビリティを別ジョブでも装備）
- 装備
- ジョブ解放
- 3〜5連戦の単発ダンジョン
- セーブ

## フェーズ 3: 連携魔法と快適機能

- 連携魔法と連携図鑑（見つけた組み合わせの一覧）
- 1ターン巻き戻し
- 倍速
- 行動順予測（この先だれがどの順に動くかの表示）

## フェーズ 4: 見た目と音

- 仮の人形をローポリ3Dモデルに置き換え
- トゥーン調（アニメ風の陰影）の表現
- 画面効果: ブルーム（光のにじみ）、ティルトシフト（ミニチュア風のぼかし）など
- 効果音

## フェーズ 5: 深層ダンジョン

- マップの自動生成
- 階層ごとの特殊ルール

## フェーズ 6: オンライン

- フレンド
- 助っ人キャラ（フレンドのキャラを借りる）
- 協力ダンジョン（フレンドと一緒に操作）
