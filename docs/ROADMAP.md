## フェーズ 0: 基盤

- プロジェクトの雛形（TypeScript / Vite / Three.js / Vitest）と、lint・型チェック・テスト・ビルドのコマンド
- core が描画・画面・定義データに依存しないことの自動検査、シード付き乱数
- 動作確認用の画面: 高低差のある 8×8 マップ、90度ずつのカメラ回転、タップでマス選択、仮の人形1体
- GitHub Actions: PR での自動検査、main から GitHub Pages への自動公開
- CLAUDE.md、本ロードマップ、GAME_DESIGN.md

**完了の目安**: 公開ページをスマホで開き、マップを回転させながらマスをタップして高さと地形を確かめられる。

## フェーズ 1: 戦闘コア

1マップ・4ジョブで、1回の戦闘が最初から最後まで遊べる状態にする。2段階に分けて作る。

### 1-1: 基本の戦闘（戦士・弓使いの2ジョブ）

- 移動（高低差による移動制限を含む）
- 通常攻撃（高低差による命中・威力などへの影響を含む）
- 向き（正面・側面・背面での違い）
- 行動順（CT 方式）
- 敵 AI（コンピューターが操作する敵の思考）
- 勝敗判定（このフェーズでは全滅のみ。ほかの勝敗条件はフェーズ2）

**完了の目安**: 戦士と弓使いを動かして、高低差と向きを考えながら敵と戦い、勝ちか負けまで1戦を遊び切れる。

### 1-2: 詠唱魔法（魔法を使う2ジョブを追加）

- 詠唱（指定から発動までの待ち時間）のある魔法
- 魔法を使う2ジョブの追加（合計4ジョブ）

**完了の目安**: 詠唱中に対象が逃げたり詠唱者が狙われたりする駆け引きを含めて、4ジョブで1戦を遊び切れる。

## フェーズ 2: 育成ループ

戦闘 → 育成 → 次の戦闘、の繰り返しが楽しめる状態にする。

- JP（ジョブポイント。戦闘で得てアビリティ習得に使う）
- アビリティ継承（覚えたアビリティを別ジョブでも装備）
- 装備
- ジョブ解放
- 勝敗条件の種類（護衛、特定の敵の撃破、指定マスへの到達、ターン制限）と、マップ上のイベントの仕組み
- 3〜5連戦の単発ダンジョン
- セーブ（この時点では端末内に保存。オンライン機能を入れる時にサーバーへ移す）
- バランス検証用のコマンド: AI 同士を自動で多数回戦わせて、勝率を集計する

**節目**: 知人に遊んでもらい、感想を集める。

**完了の目安**: ダンジョンで戦って JP をため、アビリティを覚えて編成を変え、次のダンジョンに挑む流れを、セーブを挟みながら繰り返せる。

## フェーズ 3: 連携魔法と快適機能

- 連携魔法と連携図鑑（見つけた組み合わせの一覧。図鑑の細部は GAME_DESIGN.md「未確定のアイディア」を参照）
- 1ターン巻き戻し（乱数の状態も巻き戻す）
- 倍速
- 行動順予測（この先だれがどの順に動くかの表示）

**完了の目安**: 味方の詠唱に別の魔法を合わせて連携魔法を発動でき、失敗した1ターンを巻き戻したり倍速で進めたりして快適に遊べる。

## フェーズ 4: 見た目と音

- 仮の人形をローポリ3Dモデルに置き換え
- トゥーン調（アニメ風の陰影）の表現
- 画面効果: ブルーム（光のにじみ）、ティルトシフト（ミニチュア風のぼかし）など
- 効果音

**完了の目安**: 仮の人形ではなく完成版に近い見た目と効果音で、これまでの内容を遊べる。

## フェーズ 5: 深層ダンジョン

- マップの自動生成
- 階層ごとの特殊ルール

**完了の目安**: 毎回違う形のマップが出るダンジョンを、階ごとに変わるルールに対応しながら潜っていける。

## フェーズ 6: オンライン

次の順番で作る。

1. アカウント（セーブデータのサーバー移行を含む）
2. フレンドと招待URL
3. 助っ人キャラ（フレンドのキャラを借りる）
4. 協力ダンジョン（フレンドと一緒に操作。サーバーが審判として結果を計算する）

**完了の目安**: 招待URLでフレンドになった相手のキャラを助っ人に借りたり、一緒に協力ダンジョンに挑んだりできる。セーブデータは別の端末からも続きを遊べる。
