# 設計書: 消された暦（第9稿）

この設計書を、物語とゲームの唯一の正とします。小説のタブは本文だけで、章ごとの細かな決めごとはここに書きます。「旧・改稿案」「チェックと提案」「Tab 1」は、第7稿までの記録です。読まなくてかまいません。人物名と地名はすべて仮です。

## 1. 核

- **ジャンル**: スマホのブラウザで遊ぶタクティクスRPG。高低差マップ、ジョブ育成、1戦10〜15分。
- **公開用ログライン**: 過去を書き換えて世界を守る時守。十二回目の任務から帰ると、妹は「最初からいなかった」ことになっていた。覚えているのは、自分の隊だけ。隊を率いて時代を渡れ。ただし、過去で戦えば、今のだれかが消える。
- **主人公トウマ**: 外の目的は、指示を書いた者を突き止め、妹の石を手放さないこと。内に必要なのは、消したものを元に戻さず（窪地で、剣を折った手を取り消す道を拒む）、残ったものを引き受けて、声に出して手渡すこと。
- **主題**: 表は「妹を消した者を追い、落ちてくる月から世界を救う」。裏は「消したものを、だれに、どう手渡すか」。
- **答えの示し方**: 台詞では言わない。終章の最後の一語「ただいま」と、結末で暦盤に「還り月」と刻む場面で示す。
- **方針**: 王道を表に、問いは裏に。結末は「返して回る」ひとつ。アニマは重要アイテムで、ジョブとは関係しない。名や歌で敵を弱らせない。名で立てた影は、プレイヤーが操作する戦力にしない。

## 2. 世界の規則

1. **★書き換えと石**: 塔の時の門で過去を変えると、隊が帰りの門をくぐる瞬間に今が変わる。古い流れでしか生まれなかった人は消え、生きたはずの場所に石（アニマ。古い言葉で魂）として出る。新しい流れで生まれる人もいる。だれが消えるかは、帰って照らし合わせるまで分からない。石は、ユナの作った灯と時の門の光の中でだけ、生前に口にした言葉と節を返す（灯はねじ三十回で一晩もち、数回ではすぐ切れる）。書き換えの瞬間に門の向こうにいた者は消えない（ガレス、塔の祖）。〔見せる: 序章、第1章。使う: 全体〕
2. **覚えている者**: 書き換えの瞬間に過去か門の間にいた者だけが前の世界を覚えている。門の間に入れるのは長と補佐だけ。消された人の体の癖は、周りの人に残る（四膳目の箸、二つの蜜菓子、二人分の寝藁）。
3. **砦と門**: 塔の門は砦を目印に、その時代の狙った時と場所へ降りる。砦が立つ間は暦が縫い留められ、月を呼ぶ節では門が開かない。砦の結界は時守の手でしか崩せない。要石が多いほど門は古い時代へ届き、砦の輪の要石を抜くと砦は落ちる。正しくくぐった者は出てきた門へ帰れる（ガレスは落ちただけなので帰れなかった）。マルタは砦の跡に一晩だけ仮の杭を立てられる。
4. **聞く者と影**: 光なしで石の声が分かるのは、シェラ、新月の家の者、ルゥ。ガレスはアスタルの民の石の声だけを聞ける（王家の血）。ミオは石鳴りが強く聞こえる。名を知る者が呼べば、石は生前の姿の影として立つ（声も意思もなく、体の癖で動く。強い命令のまま消された石は抜け殻になる）。倒れた影は石に戻る。
5. **★要石**: 大きな書き換えのたびに、消えた血筋の最後の一人のもとに一つ生まれ、時の門を動かす。要石は、その人と共に暮らした者にだけ応える。消える前の流れで共に暮らし、今は覚えていない者も含む（門を動かす力は別で、だれが据えても働く）。その者のそばでだけ、光なしでも節を鳴らし（言葉は返さない）、離れると鳴りやむ。要石は最後の一人の声を芯に、その血筋の声を抱く。芯の者と共に暮らした者が一人も残っていない石は、声がひとつにまとまらずにざわめく（名のない石）。欠けた節の終わりを足して届かせられるのも、その者の声だけ（血や、旋律を知っていることでは届かない）。塔は要石を石蔵に納めて独り占めする（例外はユナの石、名のない石、遺跡の古い要石）。〔見せる: 第7章の円卓。使う: 窪地、月の場面、結末の家〕
6. **★継ぎ目**: 書き換えた日は継ぎ目になって固まり、門はそこへ降りない。その日に消えた者の石を月の核の火で燃やせば、燃えている間だけ、火の中にその日が開く（丘の日ならアスタルの民の石。ユナの石もその一つ）。くぐった者は、その日に最初に立った時点の自分に重なり、今の記憶を持ったまま動ける（トウマなら十二回目の任務で丘に降り立った時）。燃えた者は、燃えはじめた時から、くぐった先のどの流れにも戻らない（引き抜いても同じ）。〔見せる: 第4章のガレス。使う: 窪地〕
7. **★月の火**: 石を燃やせる火は、月の核とそのかけらにしかない。継ぎ目を開けられるのは核の火だけで、かけらの火は石を食うだけ。石は節を鳴らしている間しか燃えない（言葉を返している間は燃えない。光の中で言葉を返すか節を歌うかは、その石が生前に残したものによる）。終わりから燃え、燃えきれば砂になり、月の糧になって戻らない。燃えきる前に引き抜いた石は、節の終わりが欠けたまま残る。焼かれた石は、熱が引くまで節を鳴らさない。月の火（核とかけら）に寄せられた石は、灯や門の光の中でも言葉を返さず、節だけを鳴らす（だから灯では燃えるのを止められない。第8章でイェルマがかけらを寄せて見せる）。月が眠って暦の外の奥へ退けば、核の火には手が届かず、どの継ぎ目も二度と開かない。〔見せる: 第8章のハナ（機を織る節で燃え、終わりから短くなって砂）。使う: 窪地、月の場面〕
8. **★月**: 還り月は、名（名を持たない人々では、その人を呼び分ける節）を呼ばれて送られた死者を抱いて眠る大精霊だった。送る者の絶えた死者は抱かれずに重さとして積もり、月はその重さに飢えて落ちた。消された者の石も同じで、核に食わせるほど月は重くなる（「糧」と「落ちる」は同じ道）。落ちた後の世の者たち（塔の祖）が輪をくぐって月を消した。これが最初の書き換え。獣の時代は落ちる前の最後の時代で、月が二つある。消された月は千年飢えて蝕に堕ち、近づくほど疫や長雨が増える。月は終わりの三つの音まである子守歌で眠り、眠ると送られた死者をまた抱く。札の裏の名を読むほど石の音は低くなり、月は眠り続ける。暦盤に名を返されると、月は元の名を取り戻す。時の門の光は、輪の石が月に引かれて灯る光で（月が名を取り戻すまで消えない）、門の光の中で石が食われると強まる。〔見せる: 序章、第2章、第5章、第8章。使う: 月の場面、刻む場面〕
9. **節**: ユナの鼻歌（終わりの三つの音まで）が眠りの節で、王家の子守歌と同じ。氏族の月を呼ぶ節は、終わりの三つの音を欠いた形。名を持たない人々の送りの節は、旋律の前半。
10. **月の居場所**: 月を呼ぶ節で開いた門は、月のいる所へ着く。都の空の星の欠けと黒い円は月の影で、石と同じ音でだれの耳にも鳴りはじめた時（第8章の終わり）に、月は今の空に現れる。その後、門は獣の時代ではなく、暦の外（月の飢えが広げた灰の原）へ開く。眠った月は暦の外の奥へ退き、どの時代の空にも見えない。眠った月は、月を呼ぶ節にも応えない。今の空の銀の月は獣の時代の小さい方で、名を呼ばれて送られた死者の光は、その奥へ昇る。
11. **新月**: 月に歌を捧げ、月を呼ぶ節を伝えてきた家で、消された者の声を聞く役目を千年負わされてきた。アスタル王家は、眠りの節を親が子に毎晩歌って守ってきた家。イェルマが建国の日を勧めたのは、その家を国ごと消して、節を持つものを要石ひとつにするため。愛された石ほど強い糧になるので、ユナをトウマの家の戸口に置いた。第8章でユナの石を焼かないのは、かけらの火では丘の朝が開かないから。第4章でガレスに「火のありか」を教えようとして断られたのもイェルマ。終章の後、暦の外に残って名を歌い続けるのは、本人が選んだこと（光の道を見ない）。窪地のイェルマは、どちらに転んでも勝つ手を打つ（石が燃えきれば最強の糧になり、眠りの節も消える。トウマがくぐれば、節を足せる声が暦の外からいなくなる）。外れたのは、トウマが引き抜き、自分の声で足したことだけ。朔（イェルマ）と弦（ヴァイス）は月が落ちると承知している。晦（蔵番の爺）は「みな戻る」としか知らされていない。裏の名は会話で使わない。
12. **門の終わり**: 月が眠っても、名を取り戻すまでは輪はまだ光り（要石を据えた輪だけ）、来た者を帰せる。新しい日にも継ぎ目にも降りない（核の火はもう届かない）。暦盤に「還り月」と刻まれて月が名を取り戻すと、どの時代の輪も光らなくなる。だれも新しく消されない。刻む場面に賭けは置かない（丘の朝は、窪地で光が閉じた時に閉じている）。輪の光が消える前に、別の時代から来た仲間は自分の時代へ帰る。ルゥだけが、自分で選んで都に残る。

## 6. 台詞と表現の決まり

- **トウマ**: ごく短い常体。答えない。言葉は章ごとに少しずつ増える。終章で口にするのは「ただいま」だけで、それまでは仕草で答える（鼻歌は台詞に数えない）。
- **使わない言葉**: 「静か」（終章のイェルマの一度だけ）、「初めて」（使わない）、イェルマについての「細い」、石の「悲鳴」、「狂人」（台詞でも「賊」）、主題を言い切る地の文。食われた石は「砂」、蝕の体は「灰」。
- **繰り返す言葉**: 「おかえり」（序章のユナ、第1章の石、終章の石）、「ただいま」、「良い仕事だ」（序章と結末）、「聞くかどうかは、お前が決めろ」（第6章だけ。結末の最上階では、帳面を開く動作で示す）。
- **終章の音の順**: 窪地では、隊が着くと石が鳴りはじめ、節が歌うたびに終わりから短くなる → 丘の氏族の歌と重なる → 三つの音の手前で丘の歌だけが途切れる → 石の節はその先へひとつだけ上がって焼けてかすれる → トウマの指が灯の底を叩き、一つ目だけが石の上がった音と重なる → 指は次の音を待つが、石は鳴らず、焼ける音だけ → トウマが灯を外し、底の字の上で残りの二つを自分で叩く（何にも重ならない）→ 石の次の節には三つの音がない → 引き抜かれた石は黙る（「止まる」は月の場面まで取っておく。窪地に劇伴は付けない）。蝕の後は、石の節がかすれて止まる → ガレスの歌が届かずに止む → 無音の一拍 → トウマの鼻歌（上手には歌わない。一度きり）→ ルゥとシェラが重なる → 月が退く → 無音 → イェルマ「……静か」→ だれも動かない間（劇伴は「おかえり」まで戻さない）。勝ち鬨や戦果の言葉は添えない。「おかえり」と「ただいま」の間を地の文で埋めない。
- **配慮**: 子どもの声の石はスズだけ。灰になる石は大人。津波を思わせる描写は使わない。子どもの仲間は後列。イェルマの「眠れた夜を知らない」は、血筋の務めとして描く。名を持たない人々を、外の者が導く形に描かない（外の者は、立ち会うだけで止めも教えもしない）。ユナの石は焼けても砂にならず、縁が欠けるだけ。描写は熱と煙と音にとどめ、苦痛の声は描かない。月の落下に「波」の画を添えない。
