# ゲーム脚本 序章「正しい仕事」

小説の序章をもとにした、ゲーム用の脚本です。小説の本文は変えていません。地の文は、人形の動き、カメラ、物、音に置き換えました。

- **会話の合計の見込み:** 約7分10秒（戦闘の操作時間を除く）
- **台詞の数:** 本文の表を数えた数（下の「検査」の欄）
- **表の種類:** 札、字幕、台詞、動き、カメラ、物、音、操作、戦闘の9つ
- **台詞の書き方:** 話者「台詞」。初めて出る人物は、話者の後に〔肩書き〕を付けます。肩書きは、顔の枠の名の下に一度だけ出します。顔の出ない声は、話者に「（声のみ）」と添えます
- **小説にない台詞:** 新しく作った台詞はありません。地の文の中の言葉を台詞の枠に移したものが4つあり、表の中に【地の文から】と理由を書いています

## 改訂の決まり（2026-11-18）

発注者の「初めて見る人には意味が分からない」という指摘を受けて、次の決まりを加えました。第1章以降も同じ決まりで書きます。

- **場所と時の札:** 場面が変わるたびに、画面の隅に短く出します。例は「今　暦の塔」「過去　アスタルの丘　建国の朝」。時をまたぐ物語なので、時守のいる時代には「今」か「過去」を必ず付けます。字幕の行数には数えません
- **字幕の順番:** 場面の頭の字幕は、暗転の上に出してから画を見せます。人物が並んだ後に時の字幕を出すことはしません
- **肩書き:** 初めて出る人物の顔の枠に、一度だけ肩書きを添えます。伏せておく事柄（正体、後の章で明かす関係）には触れません
- **前提:** 最初の戦闘の前に、時守が何者かと、今いるのが過去であることを字幕で示します。場面1だけは、字幕を3行まで認めます
- **意味ありげなカット:** 伏線のために映す物は、何秒映すかを書きます。長く止めません
