# 台本の書き方（手引き）

物語の会話は「台本」というテキストで書きます。**ゲーム脚本**（[story/game-script-prologue.md](story/game-script-prologue.md) など）から台本を起こす時に使ってください。
画面に出す台詞・動き・音はゲーム脚本が正で、小説の本文（[story/novel.md](story/novel.md)）は意図を確かめるための資料です。小説の文章を、そのまま画面に出しません。
ゲーム脚本にない台詞は足しません（CLAUDE.md の「物語の決まり」）。

- 台本の置き場所: `src/data/story/scripts/` の `.ts` ファイル。1つの台本を `export const 台本の名前 = \`…\`;` の形で書きます
  （`` ` `` と `` ` `` の間が台本の本文）。台本の名前（例: `prologueHome`）は、章のデータと戦闘のイベントから引く名前です。
- 新しいファイルを作ったら、`src/data/story/scripts/index.ts` に1行足します。
- 書き間違いがあると、テスト（`npm test`）が「台本 ○○: 3行目: 仕草「おじぎ」はありません」のように、何行目がどう悪いかを知らせます。
  行の番号は、`` ` `` の直後の改行を1行目として数えます。

## いちばん大事な方針: 見せる。文で説明しない

**見せられるものは、人形の動き、カメラ、物、音で見せる。文で説明しない。**
小説の地の文（「トウマは足を止めずに言った」「椀が三つ並んでいた」）は、台本では動きに置き換えます。

| 小説の地の文 | 台本での見せ方 |
| --- | --- |
| 戸を開けると、食卓に椀が三つ並んでいた。 | `@歩く トウマ 2,3` → `@カメラ 椀3 近 2秒`（椀を三つ置いておく） |
| 母は一膳を引き出しに戻した。 | `@片付ける 箸4 母` |
| ハルドは紙包みをひとつトウマに放った。 | `@渡す ハルド トウマ 紙包み` |
| 二人は並んで橋まで歩いた。 | `@同時 @歩く ユナ 4,4 @歩く トウマ 5,4` |
| しばらく、だれも何も言わなかった。 | `@間 2` |

語り（地の文）は、**どうしても動きで見せられない一言**（前提・世界の決まりなど、ゲーム脚本の「字幕」の行）だけに使います。
場所と時は、字幕ではなく**場所と時の札**（`@札`）で出します（ゲーム脚本の「札」の行。場面が変わるたびに付ける）。

## ゲーム脚本の行と台本の対応（`@脚本`）

ゲーム脚本の表の1行ずつを、台本の1つの指示の組として書きます。組の始めに `@脚本 場面-行` の印を付けます（台詞の行は、その行の後ろに付けます）。
印から次の印までが、その行を作る指示です。テスト（`src/data/story/gameScript.test.ts`）が、脚本の表を読んで次を確かめます。

- 脚本の行（戦闘の途中の行を除く）ごとに、台本にちょうど1つの印がある。印は脚本の行の順に並ぶ。
- 台詞の行は、脚本の話者と文のまま（【地の文から】などの注は出さない。「（声のみ）」の話者は `@顔なし`）。字幕の行は脚本の文のまま（「 / 」は字幕の改行 `／`）。
- 物の行に書かれた文字（「」の中）は、物の文字（`@文字`）で出す。動き・カメラ・物・音の行は、それを見せる指示を持ち、台詞も語りも足さない。
- 札の行は、`@札` で脚本の文のまま出す。字幕の行が「暗転の上に出す。「…」」なら、その字幕に `@暗転の上` を付ける。台詞の行の〔肩書き〕は、台本でも話者の後に書く。
- 「（1.5秒で次へ）」のように秒の書かれたカットは、`@映す` か `@文字 秒` で、その秒で次へ移る。
- 脚本の「操作」の行（歩かせる・タップ・聞く）は、その行の組に書く。脚本にない演出をゲームとして足す時（章の題）は `@脚本 外` の組に書く。
- 実装した台本の「画面に出るものだけ」は、`npm run script-export` で書き出せる（札・字幕・台詞・物の文字・名札・操作の案内を、場面ごとに出る順に。伏線のカットの秒数と場面の光も）。
  `npm run script-export -- --all` で、動き・物・カメラ・画面（暗転と明転）・間・音・操作・場所と、脚本の行の印（―― 脚本 4-2 ――）も、台本の指示の順に種類つきで出す（文字以外の演出も確かめるため）。

```
@脚本 2-5
{時守|ときもり}が帰りの門をくぐる時、世界は書き換わる。／前の世界を覚えているのは、過去にいた時守だけ。 @暗転の上
@脚本 2-6
@場所 stage-hearing
@登場 ハルド 2,1 南
@明転 0.6
@札 暦の塔 話を聞く部屋
@脚本 2-7
@カメラ 2,2 中 0.8秒
ハルド〔塔の監督官〕「下流の村は、別の場所に建った。それだけだ」 @脚本 2-8
```

## 読む量の決まり（台本の検査）

台本を読み込む時に、次の決まりを検査します（`src/core/scriptRules.ts`。数値は `src/data/story/scriptRules.ts`）。

| 決まり | 数値 |
| --- | --- |
| 台詞の字数 | 1つの枠に **40 字以内**（ルビの読みは数えない。句読点は数える） |
| 同じ人物の台詞 | 制限なし（序章の演出の直しで、台詞を意味の切れ目で分けるために外した。発注者の指示。以前は3枠まで） |
| 1つの場面（1つの台本）の字幕 | **4 行まで**（5 行以上あったら知らせる。画面に出る行で数え、`／` で改行した字幕は2行。札・物の文字・物の名前の札は数えない。序章の演出の直しで、2 行（場面1だけ 3 行）から緩めた。分かりやすさのために超える場面は `scriptRules.ts` の `narrationLimits` に書く） |
| 字幕の画面の1行 | **40 字以内**（`／` で改行した行ごと。ゲーム脚本の字幕がこれを超える時は、脚本を優先し、`scriptRules.ts` の `captionExceptions` に例外として書く） |
| 物の文字 | 台詞と同じ 40 字以内（人物の台詞の続きには数えない） |

- 合わない所は「台本 prologueHome: 30行目: 台詞が 56 字あります（1つの枠に 40 字まで）」のように、何行目かを付けて知らせます。
  一覧は `npm run script-rules` で出せます（序章の場面ごとの見込みの時間も出します）。
- 序章をゲーム脚本に差し替えたので、**決まりに合わない台本はテストの失敗**になります（`src/data/story/scriptRules.ts` の `ENFORCE_SCRIPT_RULES` が `true`）。
- 長い台詞は、2つの枠に分けるより先に、動きや物で見せられないかを考えます。
- **台詞と字幕は、意味の切れ目で2つ以上の枠に分けてよい**（序章の演出の直し）。言葉は足さず削らず、伏線になる台詞の位置も変えません。
  分けた枠は、同じ `@脚本` の印の組に続けて書きます（テスト `gameScript.test.ts` が、つなぐと脚本の文になることを確かめます。分けた所の句点だけは省いてよい）。

## 1行の書き方

1行に1つ。上から順に進みます。

| 書き方 | 意味 | 例 |
| --- | --- | --- |
| `話者「台詞」` | 台詞。枠に顔の枠・名前の札・台詞が出て、マップ上の話者の頭上に印が出る | `ユナ「おかえり」` |
| それ以外の文 | 語り（地の文）。枠なしの字幕として画面の上（暗転中は中央）に出る | `一日前。` |
| `「…」と母が言った。` | 「 で始まる行も語り | `「だれ？」と母が言った。` |
| `@指示 …` | 指示だけの行（全角の ＠ でもよい） | `@暗転 1` |
| `話者「台詞」 @指示 …` | 台詞の前に指示を行う（後ろに何個でも続けられる） | `トウマ「ああ」 @仕草 トウマ うなずく` |
| `話者「台詞」 @顔なし` | この台詞では顔の枠を出さない | `声「……」 @顔なし` |
| `話者「台詞」 @強調なし` | この台詞では、マップ上の話者に印を出さず、カメラも寄せない | `ユナ「ねえ」 @強調なし` |
| `物の呼び名「文」 @文字` | 物に書かれた文字（札・封蝋の印）。画面の中ほどに、紙の札のように読める大きさで出す。直前に `@カメラ 物 近` で物を大きく映す | `封蝋の印「未来より」 @文字` |
| `@同時 @指示 … @指示 …` | 同じ行の指示を同時に起こす（すべて終わるまで待つ） | `@同時 @歩く ユナ 4,2 @歩く トウマ 3,3` |
| `話者〔肩書き〕「台詞」` | 初めて出る人物の肩書き。その台詞の時だけ、名前の札の名の下に出す（伏せておく事柄には触れない） | `トウマ〔時守〕「ユナは」` |
| `字幕 @暗転の上` | 暗転の上に出す字幕。暗くなっていなければ暗転してから、画面の中央に出す。場面の頭の字幕は、こうして画を見せる前に出す | `一日前。トウマたちは、遠い過去の谷にいた。 @暗転の上` |
| `物の呼び名「文」 @文字 1.5秒` | 物の文字を、その秒だけ出して次へ（タップでも進む）。終わりを全角の空白で区切った短い名は、右に寄せた署名になる | `封蝋の印「未来より」 @文字 1.5秒` |
| `#` で始まる行、空の行 | 読み飛ばす（メモに使う） | `# ここからユナの部屋の夜` |

- 台詞の行は、指示の前を必ず `」` で終えます。話者の名前に空白は入れません。
- **字幕の改行**: 語りの中の `／` は改行（2行の字幕）。
- **ルビ（読み仮名）**: `{漢字|かんじ}`。台詞にも語りにも書けます。例: `{堰|せき}を崩す`。
  小説の初出の「堰（せき）」の形は、台本では `{堰|せき}` に直します。
- 場所は `x,z`（マスの横,奥行き。左奥が 0,0）。向きは `北・東・南・西`。

## 台詞の見せ方

- **顔の枠**: 台詞の枠の左に、話者の胸から上が出ます。絵は要りません（その人物の人形を別のカメラで写します）。
  マップにいない人物（声だけ、など）でも、人物の見た目（下の「人物の見た目」）から写します。出したくない台詞には `@顔なし`。
- **名前の札**: 人物の服の主な色で、名前を大きく出します。色は人物の見た目（`looks.ts` の body と accent）から自動で決まります。
- **肩書き**: `@肩書き タリス 八の席` と書くと、その台本の終わりまで、名前の札に「タリス　八の席」と出ます。`@肩書き タリス なし` で外します。
- **話者の強調**: 台詞の間、マップ上の話者の頭上に小さな印が出て、カメラが少しだけ話者へ寄ります。強調したくない台詞には `@強調なし`。
  寄せる量は控えめです。大きく見せたい時は `@カメラ 名前 近` を使います。

## 指示の一覧

| 指示 | 書き方 | 内容 |
| --- | --- | --- |
| 登場 | `@登場 名前 x,z 向き` | 人物の人形がそのマスに現れる |
| 退場 | `@退場 名前` / `@退場 ガレス 落ちる` | 人物が消える。戦闘のマップの上では、光にさらわれるように上へ消える。`落ちる` を添えると、横へ押し流され、白く光りながら足もとの下へ落ちていく（時の外へ落ちる） |
| 歩く | `@歩く 名前 x,z [速さ]` | そのマスまで歩く（縦に進んでから横に進む）。速さは ゆっくり・ふつう・速く・走る（省くとふつう） |
| 位置 | `@位置 名前 x,z` | 動かさずに置き直す |
| 向き | `@向き 名前 北` / `@向き 名前 相手の名前` | 向きを変える（相手の人物か物の方を向く） |
| 仕草 | `@仕草 名前 仕草の名前` | 短い動き（下の一覧） |
| カメラ | `@カメラ x,z 近` / `@カメラ 名前 中` / `@カメラ 灯 近 3秒` | そのマスか人物・物へカメラを向ける。寄りは `遠・中・近`（省くと今のまま。`遠` で引く）。秒を書くと、その時間をかけてゆっくり動く。`待たない` を添えると（`@カメラ 4,15 遠 4秒 待たない`）、動き終わるのを待たずに次の字幕や台詞へ進む（字幕を読ませながら、堰から下流の村へカメラをたどらせる）。マップの外へ向ける時は、戦場か会話用マップの `lookouts` にそのマスを書く。マスに `人の高さ` を添えると（`@カメラ 7,2 人の高さ 近 1秒`）、そこに人が立っている時と同じ高さで映す（だれもいなくなった所を、人がいた時とまったく同じ構図で映す） |
| 暗転 | `@暗転 秒` | 画面を暗くする（秒を省くと 0.6 秒）。暗いまま語りを出せる |
| 明転 | `@明転 秒` | 暗転から戻す |
| 間 | `@間 秒` | 少し待つ |
| 置く | `@置く 物の名前 種類 x,z` | 物を置く。物の名前は台本の中で付ける呼び名（`椀4` など） |
| 消す | `@消す 物の名前` / `@消す 椀*` / `@消す *` | 物を消す（椀が四つから三つになる、など）。終わりが `*` なら、その名前で始まる物をすべて（`*` だけなら全部。部屋の中身の入れ替えに） |
| 片付ける | `@片付ける 物の名前 [人物の名前]` | 人物が物の方を向き、拾う仕草をしてから物が消える（人物を省くと消すと同じ）。`椀*` も使える |
| 変える | `@変える 物の名前 種類` | 物の種類を変える（`@変える 灯 ともった灯` で灯がともる） |
| 押し続ける | `@押し続ける 段数 手の近くの文` | 操作の場面。ボタンを押し続けると少しずつ進み、離すと止まる（ねじを巻く）。1行に分けて書く |
| 歩かせる | `@歩かせる 名前 x,z x,z …` | 操作の場面。プレイヤーが光るマスを押して1マスずつ歩かせる。進む順に書き、最後が行き先。最初のマスは今いるマスの隣。1行に分けて書く |
| 姿勢 | `@姿勢 名前 座る` / `@姿勢 名前 立つ` | 続く姿勢（座る・膝をついたまま など）。「立つ」で元に戻す。仕草は、続く姿勢に重ねて動く |
| 持つ | `@持つ 名前 物の種類 腰` | 人物に持ち物を付ける。付ける所は 手（右手）・左手・腰・背（省くと手） |
| 離す | `@離す 名前 腰` | その所の持ち物を外す（見た目の決まりで持っている物も外れる） |
| 渡す | `@渡す 名前 相手の名前 物の種類 [持つ所]` | 相手の方を向いて手渡す。渡す人の右手が空になり、相手の持つ所（省くと手）に物が付く |
| 肩書き | `@肩書き 名前 肩書き` | 名前の札に肩書きを添える（台本の終わりまで。`なし` で外す） |
| 同時 | `@同時 @指示 … @指示 …` | 同じ行の指示を一斉に始め、すべて終わるまで待つ（操作の場面と章題は入れられない）。`@間 2` を入れると、少なくとも 2 秒は待ち、その後ろに書いた指示は 2 秒遅れて始まる（例: `@同時 @映す テオの手もと 近 3 @物の札 イェルマの手もと 守り袋 1秒 @間 1.1 @渡す イェルマ テオ 守り袋`） |
| 光 | `@光 呼び名 x,z 白` / `@光 呼び名 人物の名前 金` | 光の柱を立てる（帰りの門の光など）。人物に立てると、人物について動く。戦闘の舞台では「トウマの後ろ」のように書くと、その人物の背中側の隣のマスに立てる（序章の丘の帰りの門）。色は 白・青・金（省くと白） |
| 光を消す | `@光を消す 呼び名` | 光を消す |
| 節 | `@節 旋律の名前 音色 [印に添える文]` | 旋律を鳴らす（待たずに次の行へ進む）。音色は 鼻歌・石・歌声。鳴っている間、画面の上に「♪ 鼻歌」などの印が出る（文を添えるとその文） |
| 節を待つ | `@節を待つ 3` | 鳴っている旋律の、終わりから 3 個目の音が鳴りはじめるまで待つ（数を省くと終わるまで）。直後に `@仕草 ユナ 三度叩く` と書くと、終わりの三つの音に指が重なる。早送りの時は待たない |
| 節を止める | `@節を止める` | 旋律を止める（会話が終わる時とスキップした時も止まる） |
| 音 | `@音 効果音の名前` | 効果音を鳴らす（攻撃・命中・ミス・魔法・決定・取り消し・門・折れる・石の音・水）。門・石の音・水・折れるは、画面にも「♪ 石の鳴る音」などを短く出す |
| 章題 | `@章題 序章 正しい仕事` | 章の題を画面いっぱいに出す（タップか約4秒で次へ）。1行に分けて書く |
| 攻撃 | `@攻撃 ゴード ガレス 払う` | 戦闘中の台本だけ。攻撃の動きを見せる（見た目だけで、戦闘の結果は変えない）。隣なら斬りかかり、離れていれば矢を放つ。結果は 当たる・外れる・払う（省くと当たる） |
| 押し返す | `@押し返す ゴード` | 戦闘中の台本だけ。人物が、向きを変えずに滑るように、戦闘の中の自分のマスへ下がる（`@歩く` で前に出した後に使う） |
| 巻きつく | `@巻きつく ガレス` | 戦闘中の台本だけ。開いている帰りの門（`@光`）の光が、帯のように伸びて人物に巻きつく（人物はまだ消えない）。その後の `@退場 ガレス 落ちる` で、巻きついた光ごと白い穴へ引き込まれる。間に `@仕草` を書けば、巻きつかれたまま動く |
| 脚本 | `@脚本 2-5` / `@脚本 外` | ゲーム脚本の行の印（上の「ゲーム脚本の行と台本の対応」）。舞台は変えない |
| 声 | `@声 番兵 叫び` | 言葉にしない声（叫び・呼び込み・笑い）。短い合成音と、人物の頭上の小さな絵の印で表す（文字にはしない） |
| 音の印 | `@音の印 ユナ 4.5秒` | 鼻歌など、だれが鳴らしている音かを見せる。人物の頭上に音符の印を、秒のあいだ出す（秒を省くと 6 秒。待たない） |
| 遠景 | `@遠景 stage-far-valley 3` | 離れた場所を映す短いカット。会話用の小さなマップを、暗転でつないで秒の間だけ見せ、元の場所へ戻る（戦闘の後の台本でも使える）。マップの `view` にカメラを向け、`sky` で空の色を変えられる。1行に分けて書く |
| 場所 | `@場所 stage-hearing` | 場所を移す（会話用のマップを切り替える）。人物と光はいなくなり、物は新しいマップに置いておく物になる。続けて `@登場` で人物を出す。1行に分けて書く |

### 足す時は

- **仕草**: `stageDefs.ts` の GESTURES に1つ足す。時刻（0〜1）ごとに姿勢の値を並べるだけで、絵は要りません。
- **物**: 形を `src/data/story/models.ts` に足し（箱・円柱・円すい・球・輪・多面体の組み合わせ）、台本の名前を `stageDefs.ts` の PROP_KINDS に足す。
- **人物の見た目**: `src/data/story/looks.ts` に足し（服の形と色・髪の色と形・肌の色・背の高さ・体の幅・持ち物。上の「人物の見た目」）、台本の名前を ACTOR_LOOKS に足す。
- **旋律**: `src/data/sounds.ts` の MELODIES に「音の高さ 長さ」の列で足す（例: `'E4 1'` はミの音を1拍）。
  今ある節: ユナの鼻歌（終わりの三つの音まで）・月を呼ぶ節（丘の歌。終わりの三つの音を欠いた形）・送りの節（旋律の最初の句だけ。第5章で使う）。
- **会話用のマップ**: `src/data/story/stages.ts` に、文字の行で足す（1マスは「高さ + 地形の文字」。g 草地・d 土・s 岩場・w 水・b 板張り）。
  場面の始めから置いておく家具は、マップの定義の props に書く。壁は、マスの高さで積むより、壁の形の物（家の殻のような物）で描くと、手前の壁を低く切って人物を隠さずに済む。

  `cameraHeight`（0 低い・1 標準・2 高い。低いほど顔が見える）で、そのマップの台本のカメラを整える（トウマの家）。

## 場面と章（`src/data/story/books.ts`）

物語は「章」と、その中の「場面」の列です。場面は4種類あります。

| 場面 | 書き方 | 内容 |
| --- | --- | --- |
| 会話 | `{ kind: 'dialogue', id, scriptId: '台本の名前', stageId: '会話のマップ' }` | 小さなマップの上で台本を進める |
| 操作の場面 | `{ kind: 'interactive', id, scriptId, stageId }` | 押し続ける・歩かせる を含む台本（見せ方は会話と同じ） |
| 戦闘 | `{ kind: 'battle', id, battleId: '戦場の id' }` | 出撃前の配置から戦う。勝つと次の場面へ |
| 拠点 | `{ kind: 'base', id }` | 編成と店。「物語を進める」で次へ |

- 章には「これまで」（`recap`）を3行以内で書きます。続きから再開した時に出ます。
- 場面には、ゲーム脚本の場面の番号（`scriptScene`）を書きます。確認用の機能の「場面を選ぶ」に「序章 場面4 家・夕食とユナの部屋の夜」のように出ます（名前は `src/ui/text.ts` の `story.scenes` に場面の id で書く）。
  脚本の1つの場面を戦闘の前と戦闘に分けた時は、両方に同じ番号を書きます。
- 会話のマップは `src/data/story/stages.ts`。
- 進み具合は場面の区切りで保存されます。会話の途中で閉じると、その会話の始めからやり直します。
- 場面に `recap` を書くと、その場面から再開した時の「これまで」になります（後の場面で書くまで続く）。章の「これまで」は、章の冒頭（2つ目の章から）と、
  場面の `recap` がない時の再開で出ます。
- 戦闘の場面に `partyId` を書くと、その章のために決めた部隊（`src/data/story/parties.ts`）で戦います（育てた部隊の強さに左右されない）。

## 戦闘中の会話と地形の変化（戦場の定義の `events`）

- 起きること `{ kind: 'dialogue', scriptId: '台本の名前' }` で、戦闘中に会話の枠を出せます（戦闘の結果は変わりません）。
  戦闘中の台本では、人物の登場・物の出し入れ・操作の場面は使いません。
- 戦闘中の台本では、`@仕草`・`@向き`・`@カメラ 名前`・`@光`・`@節`・`@音`・`@攻撃`・`@押し返す`・`@渡す`・`@同時`・`@肩書き` も使えます（人物の名前は、部隊の人物の名前か、戦場の定義の `cast` に書いた名前）。
  戦闘中は、`@向き` と `@カメラ` の相手は人物だけ、`@消す 椀*` のようなまとめて消す書き方は使えません。顔の枠・名前の札・話者の強調は会話の場面と同じです。
- 起きること `{ kind: 'terrain', tiles: [{ x, z, height, terrain }] }` で、マスの高さや種類を変えられます（例: 堰が切れて水になる）。
- きっかけには、今までのもの（手番・マスに入る・HP・撃破）に加えて、`objectsBroken`（対象物が N 個壊れた）と
  `tally`（数えた回数が届いた）があります。

## 戦場の定義に書く、物語のための項目（`src/data/battles/`）

| 項目 | 内容 |
| --- | --- |
| `cast` | 台本の人物の名前 → ユニットか背景の人の id（例: `{ ガレス: 'hill-gareth' }`） |
| `looks` | ユニットの id → 人物の見た目の名前（`looks.ts`）。物語の相手を人物の見た目で出す |
| `bystanders` | 戦わない背景の人々（id・x・z・向き・見た目の名前）。対象にならず行動順にも入らない。立つマスは通れない |
| `afterVictory` | 勝った後に、戦闘のマップの上で流す台本の名前。`@光`・`@退場`（光にさらわれるように消える）・`@歩く`（見た目だけ）・`@姿勢`・`@遠景`・`@声`・`@動かす` が使える |
| `decor` | 見た目だけの置き物（砦・旗・遠景の大勢の人々）。台本の物の種類の名前で書き、マップの外にも置ける。勝った後の台本から `@動かす` できる |
| `ambient` | 戦闘の間、遠くで繰り返し鳴らす旋律（丘の歌）。勝った後の台本の `@節を止める` で止まる |
| `tutorial` | 戦闘の手ほどきの段の列。段は `{ id, mode, point }`。`unitId`（その人物の手番だけ）・`minHeight`（その高さ以上に立った時）・`tally`（数えた回数が届いてから）も書ける。mode は操作の段階（`main` 移動を選ぶ・`afterMove` 移動の後・`targeting` 相手を選ぶ・`confirm` 確定・`facing` 向き など）、point は指し示す物（`tile`・`unit`・`button`・`reachToward`）。文は `src/ui/text.ts` の `tutorial.steps` に段の id で書く |
| 配置の `minHp` | HP の尽きないユニット（HP はこの値より下がらない。序章の丘のガレス） |
| 配置の `kind` | ユニットの種類（人・影・獣。省くと人）。HP が尽きた時の動きが変わる（戦闘で人は死なない決まり） |
| 配置の `noRetire` | この戦闘では退場しない（膝をついたまま最後まで残る。序章の堰の番兵） |
| 勝利条件 `hitUnit` の `finisherId` | 最後の1回を当てられるユニット（序章の丘: 誓いの剣を折るのはトウマ） |
| 勝敗条件の `defeatAllWins: false` | 敵をすべて退けても勝ちにならない（書いた勝利条件だけで勝つ） |

## 例（序章の台本の一部。`src/data/story/scripts/prologue.ts`）

```

@節を待つ 3
@脚本 4-25
@仕草 ユナ 三度叩く
@節を待つ
ユナ「この歌、最後の三つの音が好き。聞いてると、眠くなるの」 @脚本 4-26 @姿勢 ユナ 立つ @向き ユナ トウマ
@脚本 4-27
@暗転 0.8
@場所 stage-night-sky
@カメラ 星 中
@明転 0.8
@間 3.5
```
