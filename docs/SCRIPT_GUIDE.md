# 台本の書き方（手引き）

物語の会話は「台本」というテキストで書きます。小説の本文（[story/novel.md](story/novel.md)）から台本を起こす時に使ってください。
台詞は小説の本文から取り、設計書の「6. 台詞と表現の決まり」を守ります（CLAUDE.md の「物語の決まり」）。

- 台本の置き場所: `src/data/story/scripts/` の `.ts` ファイル。1つの台本を `export const 台本の名前 = \`…\`;` の形で書きます
  （`` ` `` と `` ` `` の間が台本の本文）。台本の名前（例: `prologueHome`）は、章のデータと戦闘のイベントから引く名前です。
- 新しいファイルを作ったら、`src/data/story/scripts/index.ts` に1行足します。
- 書き間違いがあると、テスト（`npm test`）が「台本 ○○: 3行目: 仕草「おじぎ」はありません」のように、何行目がどう悪いかを知らせます。

## 1行の書き方

1行に1つ。上から順に進みます。

| 書き方 | 意味 | 例 |
| --- | --- | --- |
| `話者「台詞」` | 台詞。枠に名前と台詞が出る | `ユナ「おかえり」` |
| それ以外の文 | 語り（地の文）。名前なしで、明朝体の淡い色で出る | `戸を開けると、食卓に椀が三つ並んでいた。` |
| `「…」と母が言った。` | 「 で始まる行も語り | `「だれ？」と母が言った。` |
| `@指示 …` | 指示だけの行（全角の ＠ でもよい） | `@暗転 1` |
| `話者「台詞」 @指示 …` | 台詞の前に指示を行う（後ろに何個でも続けられる） | `トウマ「ああ」 @仕草 トウマ うなずく` |
| `#` で始まる行、空の行 | 読み飛ばす（メモに使う） | `# ここから工房の夜` |

- 台詞の行は、指示の前を必ず `」` で終えます。話者の名前に空白は入れません。
- **ルビ（読み仮名）**: `{漢字|かんじ}`。台詞にも語りにも書けます。例: `{堰|せき}を崩す`。
  小説の初出の「堰（せき）」の形は、台本では `{堰|せき}` に直します。
- 場所は `x,z`（マスの横,奥行き。左奥が 0,0）。向きは `北・東・南・西`。

## 指示の一覧

| 指示 | 書き方 | 内容 |
| --- | --- | --- |
| 登場 | `@登場 名前 x,z 向き` | 人物の人形がそのマスに現れる |
| 退場 | `@退場 名前` | 人物が消える |
| 歩く | `@歩く 名前 x,z` | そのマスまで歩く（縦に進んでから横に進む） |
| 位置 | `@位置 名前 x,z` | 動かさずに置き直す |
| 向き | `@向き 名前 北` / `@向き 名前 相手の名前` | 向きを変える（相手の方を向く） |
| 仕草 | `@仕草 名前 仕草の名前` | 短い動き（下の一覧） |
| カメラ | `@カメラ x,z 近` / `@カメラ 名前 中` | そのマスか人物へカメラを向ける。寄りは `遠・中・近`（省くと今のまま） |
| 暗転 | `@暗転 秒` | 画面を暗くする（秒を省くと 0.6 秒）。暗いまま語りを出せる |
| 明転 | `@明転 秒` | 暗転から戻す |
| 間 | `@間 秒` | 少し待つ |
| 置く | `@置く 物の名前 種類 x,z` | 物を置く。物の名前は台本の中で付ける呼び名（`椀4` など） |
| 消す | `@消す 物の名前` | 物を消す（椀が四つから三つになる、など） |
| 変える | `@変える 物の名前 種類` | 物の種類を変える（`@変える 灯 ともった灯` で灯がともる） |
| 押し続ける | `@押し続ける 段数 手の近くの文` | 操作の場面。ボタンを押し続けると少しずつ進み、離すと止まる（ねじを巻く）。1行に分けて書く |
| 歩かせる | `@歩かせる 名前 x,z x,z …` | 操作の場面。プレイヤーが光るマスを押して1マスずつ歩かせる。進む順に書き、最後が行き先。最初のマスは今いるマスの隣。1行に分けて書く |
| 姿勢 | `@姿勢 名前 座る` / `@姿勢 名前 立つ` | 続く姿勢（座る・膝をついたまま など）。「立つ」で元に戻す。仕草は、続く姿勢に重ねて動く |
| 持つ | `@持つ 名前 物の種類 腰` | 人物に持ち物を付ける。付ける所は 手（右手）・左手・腰・背（省くと手） |
| 離す | `@離す 名前 腰` | その所の持ち物を外す（見た目の決まりで持っている物も外れる） |
| 光 | `@光 呼び名 x,z 白` / `@光 呼び名 人物の名前 金` | 光の柱を立てる（帰りの門の光など）。人物に立てると、人物について動く。色は 白・青・金（省くと白） |
| 光を消す | `@光を消す 呼び名` | 光を消す |
| 節 | `@節 旋律の名前 音色 [印に添える文]` | 旋律を鳴らす（待たずに次の行へ進む）。音色は 鼻歌・石・歌声。鳴っている間、画面の上に「♪ 鼻歌」などの印が出る（文を添えるとその文） |
| 節を待つ | `@節を待つ 3` | 鳴っている旋律の、終わりから 3 個目の音が鳴りはじめるまで待つ（数を省くと終わるまで）。直後に `@仕草 ユナ 三度叩く` と書くと、終わりの三つの音に指が重なる。早送りの時は待たない |
| 節を止める | `@節を止める` | 旋律を止める（会話が終わる時とスキップした時も止まる） |
| 音 | `@音 効果音の名前` | 効果音を鳴らす（攻撃・命中・ミス・魔法・決定・取り消し・門・折れる・石の音・水）。門・石の音・水・折れるは、画面にも「♪ 石の鳴る音」などを短く出す |
| 章題 | `@章題 序章 正しい仕事` | 章の題を画面いっぱいに出す（タップか約4秒で次へ）。1行に分けて書く |
| 攻撃 | `@攻撃 ゴード ガレス 払う` | 戦闘中の台本だけ。攻撃の動きを見せる（見た目だけで、戦闘の結果は変えない）。隣なら斬りかかり、離れていれば矢を放つ。結果は 当たる・外れる・払う（省くと当たる） |
| 押し返す | `@押し返す ゴード` | 戦闘中の台本だけ。人物が、向きを変えずに滑るように、戦闘の中の自分のマスへ下がる（`@歩く` で前に出した後に使う） |

- 操作の場面には失敗も分岐もありません。初めての時だけ、操作のしかたを短く出します。
- 選択肢は作りません（分岐とマルチエンディングは作らない決まり）。

### 仕草の名前（`src/data/story/stageDefs.ts` の GESTURES）

うなずく・首を振る・背を向ける（終わった後も後ろを向いたまま）・指で数える・膝をつく・見上げる・うつむく・手を上げる・
胸に手を当てる・会釈する・驚く・深く会釈する・首をかしげる・三度叩く（作業台や灯の底を指で三度。1回の間は約 0.4 秒）・指さす・
背をさする・手渡す・腕をつかむ・振り上げる・後ずさる・耳に当てる・拾う・泣く・刻む・畳む・見回す・構える・こめかみに指を当てる・
腕を広げる・歌う・足を止める

続く姿勢（同じファイルの POSTURES）: 座る・作業する・膝をついたまま・帳面を読む（腰掛けて帳面に目を落としたまま）・うつむいたまま・背を丸める

### 物の種類（同じファイルの PROP_KINDS）

椀・灯・ともった灯・石・机・箱・瓦礫・木箱、持ち物に向く小さな物: 測り棒・小さな灯・ともった小さな灯・袋・薬箱・紙包み・守り袋・帳面・
指示書・箸・剣・折れた剣・槍・小刀・箒

### 人物の見た目（同じファイルの ACTOR_LOOKS）

トウマ・ユナ・母・父・ハルド・テオ・イェルマ・ゴード・キリ・フェン・ノノ・ガレス・ミオ・おかみ・老婆・売り子・番兵（仮の人形）。
ここにない名前（村人 など）も使えます。ふつうの人の見た目になります。

### 足す時は

- **仕草**: `stageDefs.ts` の GESTURES に1つ足す。時刻（0〜1）ごとに姿勢の値を並べるだけで、絵は要りません。
- **物**: 形を `src/data/story/models.ts` に足し（箱・円柱・円すい・球・輪・多面体の組み合わせ）、台本の名前を `stageDefs.ts` の PROP_KINDS に足す。
- **人物の見た目**: `src/data/story/looks.ts` に足し（服の色・髪の色と形・背の高さ・体の幅・持ち物）、台本の名前を ACTOR_LOOKS に足す。
- **旋律**: `src/data/sounds.ts` の MELODIES に「音の高さ 長さ」の列で足す（例: `'E4 1'` はミの音を1拍）。
  今ある節: ユナの鼻歌（終わりの三つの音まで）・月を呼ぶ節（丘の歌。終わりの三つの音を欠いた形）・送りの節（旋律の最初の句だけ。第5章で使う）。
- **会話用のマップ**: `src/data/story/stages.ts` に、文字の行で足す（1マスは「高さ + 地形の文字」。g 草地・d 土・s 岩場・w 水・b 板張り）。
  場面の始めから置いておく家具は、マップの定義の props に書く。

## 場面と章（`src/data/story/books.ts`）

物語は「章」と、その中の「場面」の列です。場面は4種類あります。

| 場面 | 書き方 | 内容 |
| --- | --- | --- |
| 会話 | `{ kind: 'dialogue', id, scriptId: '台本の名前', stageId: '会話のマップ' }` | 小さなマップの上で台本を進める |
| 操作の場面 | `{ kind: 'interactive', id, scriptId, stageId }` | 押し続ける・歩かせる を含む台本（見せ方は会話と同じ） |
| 戦闘 | `{ kind: 'battle', id, battleId: '戦場の id' }` | 出撃前の配置から戦う。勝つと次の場面へ |
| 拠点 | `{ kind: 'base', id }` | 編成と店。「物語を進める」で次へ |

- 章には「これまで」（`recap`）を3行以内で書きます。続きから再開した時に出ます。
- 会話のマップは `src/data/story/stages.ts`。
- 進み具合は場面の区切りで保存されます。会話の途中で閉じると、その会話の始めからやり直します。
- 場面に `recap` を書くと、その場面から再開した時の「これまで」になります（後の場面で書くまで続く）。章の「これまで」は、章の冒頭（2つ目の章から）と、
  場面の `recap` がない時の再開で出ます。
- 戦闘の場面に `partyId` を書くと、その章のために決めた部隊（`src/data/story/parties.ts`）で戦います（育てた部隊の強さに左右されない）。

## 戦闘中の会話と地形の変化（戦場の定義の `events`）

- 起きること `{ kind: 'dialogue', scriptId: '台本の名前' }` で、戦闘中に会話の枠を出せます（戦闘の結果は変わりません）。
  戦闘中の台本では、人物の登場・物の出し入れ・操作の場面は使いません。
- 戦闘中の台本では、`@仕草`・`@向き`・`@カメラ 名前`・`@光`・`@節`・`@音`・`@攻撃`・`@押し返す` も使えます（人物の名前は、部隊の人物の名前か、戦場の定義の `cast` に書いた名前）。
- 起きること `{ kind: 'terrain', tiles: [{ x, z, height, terrain }] }` で、マスの高さや種類を変えられます（例: 堰が切れて水になる）。
- きっかけには、今までのもの（手番・マスに入る・HP・撃破）に加えて、`objectsBroken`（対象物が N 個壊れた）と
  `tally`（数えた回数が届いた）があります。

## 戦場の定義に書く、物語のための項目（`src/data/battles/`）

| 項目 | 内容 |
| --- | --- |
| `cast` | 台本の人物の名前 → ユニットか背景の人の id（例: `{ ガレス: 'hill-gareth' }`） |
| `looks` | ユニットの id → 人物の見た目の名前（`looks.ts`）。物語の相手を人物の見た目で出す |
| `bystanders` | 戦わない背景の人々（id・x・z・向き・見た目の名前）。対象にならず行動順にも入らない。立つマスは通れない |
| `afterVictory` | 勝った後に、戦闘のマップの上で流す台本の名前。`@光`・`@退場`（光にさらわれるように消える）・`@歩く`（見た目だけ）が使える |
| `tutorial` | 戦闘の手ほどきの段の列。段は `{ id, mode, point }`。mode は操作の段階（`main` 移動を選ぶ・`afterMove` 移動の後・`targeting` 相手を選ぶ・`confirm` 確定・`facing` 向き など）、point は指し示す物（`tile`・`unit`・`button`・`reachToward`）。文は `src/ui/text.ts` の `tutorial.steps` に段の id で書く |
| 配置の `minHp` | HP の尽きないユニット（HP はこの値より下がらない。序章の丘のガレス） |
| 配置の `kind` | ユニットの種類（人・影・獣。省くと人）。HP が尽きた時の動きが変わる（戦闘で人は死なない決まり） |
| 配置の `noRetire` | この戦闘では退場しない（膝をついたまま最後まで残る。序章の堰の番兵） |
| 勝利条件 `hitUnit` の `finisherId` | 最後の1回を当てられるユニット（序章の丘: 誓いの剣を折るのはトウマ） |
| 勝敗条件の `defeatAllWins: false` | 敵をすべて退けても勝ちにならない（書いた勝利条件だけで勝つ） |

## 例（序章の台本の一部。`src/data/story/scripts/prologue.ts`）

```
@置く 作業台 作業台 7,1
@登場 ユナ 7,2 北
@姿勢 ユナ 作業する
ユナは、手のひらに収まる真鍮の灯のねじを巻いていた。見慣れない形の灯だった。 @持つ ユナ 小さな灯 左手
だれに渡すつもりなのかは、言わなかった。
@節 ユナの鼻歌 鼻歌
ユナは鼻歌を歌いながら、ねじを巻き続けた。言葉を覚える前から知っていたという、どこの歌とも分からない節だった。
@節を待つ 3
@仕草 ユナ 三度叩く
終わりの三つの音に合わせて、ユナの指が、作業台を三度叩いた。
@節を待つ
@暗転 1
窓の外は、星のよく見える夜だった。
```
