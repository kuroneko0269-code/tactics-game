- 開発計画: [docs/ROADMAP.md](docs/ROADMAP.md)
- 仕様の要点: [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)

## 手元で動かす

Node.js 22 以上が必要です。

```sh
npm install
npm run dev
```

表示された http://localhost:5173/ をブラウザで開きます。
